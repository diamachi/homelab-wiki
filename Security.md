# Security

Keep public documentation and private operations records in separate directories and repositories. A Git ignore file is only a guardrail; it does not remove data already committed.

Store credential values in a local password manager or a separately encrypted store. Document retrieval locations privately. Never publish application environment files, panel tokens, Windows credentials, SSH private keys, router backups or full container inspection output.

Restrict administrative entry points to intended networks. The source's inactive UFW status is a historical observation, not a recommended configuration or a complete security assessment.
